# صنّاع الأثر | سوهاج

موقع عربي بهوية فاتحة وصور تعبيرية ومسارات تنقل مصوّرة، وتجربة تفاعلية لتحويل اهتمام الزائر ووقته إلى بطاقة مشاركة مقترحة يمكن حفظها ومشاركتها.

## التشغيل

يتطلب Node.js 24، ولا يستخدم أي اعتماديات تشغيل خارجية.

```sh
npm ci --ignore-scripts
npm run check
npm run build
npm run dev
```

ينتج البناء ملفات ثابتة في `dist/`. يربط Vercel المستودع بفرع `main`، ويشغّل الفحص والبناء عند النشر.

## تجربة الموقع

- واجهة عربية RTL، بخطوط محلية وهوية بألوان الأوف وايت والبنفسجي والنعناعي والمشمشي.
- افتتاحية بتكوين صور وشعار أصلي مستوحى من تلاقي الطاقات، وتفاعل بسيط بالضغط أو لوحة المفاتيح.
- بوصلة الأثر: ست محطات مصوّرة، وشريط محطات عائم، ومسار تصفح يتابع القسم الحالي.
- أربعة مسارات مصوّرة للمشاركة تفتح في حوار قابل للإغلاق بلوحة المفاتيح.
- معرض صور بتكبير وتنقل بالأسهم، مع دعم Escape وإعادة التركيز لعنصر الفتح.
- بطاقة أثرك: اهتمام + وقت + مركز، ثم خطوات مقترحة وحفظ نصي ومشاركة أصلية في الأجهزة الداعمة، مع بديل نسخ أو حفظ.
- اختيار المركز متزامن بين مساحة سوهاج وأداة البطاقة.
- قائمة جوال، روابط داخلية، أسئلة قابلة للفتح، تحكم في الحركة ودعم تقليل الحركة.
- بيانات مشاركة، sitemap، robots، صفحة 404، وترويسات حماية.

## حدود المحتوى المعتمد

المعلومات المؤكدة من موجز المالك هي اسم «صنّاع الأثر» وارتباطه بسوهاج. لا يدّعي الموقع تسجيلًا قانونيًا أو شراكات أو أرقام إنجازات أو أنشطة قائمة. المجالات المعروضة مقترحات للمشاركة وموسومة بذلك. توضع البيانات الفعلية وقنوات التواصل المعتمدة عند توفرها.

بطاقة المشاركة تعمل داخل المتصفح فقط؛ لا تجمع أسماء أو هواتف، ولا ترسل طلبات إلى الفريق، ولا تنفذ تسجيلًا للتطوع، ولا تجمع تبرعات. المشاركة تتم باختيار الزائر نفسه والمستلم الذي يحدده. لا توجد خدمات إعلانات أو تحليلات أو ملفات ارتباط يضيفها التطبيق.

الرسم المستوحى من النيل عمل فني رمزي، وليس خريطة جغرافية أو بيان تغطية أو فروع. أسماء المراكز للاختيار الشخصي، ولا تدّعي وجود نشاط للفريق فيها. المرجع الجغرافي العام: [الهيئة العامة للاستعلامات — محافظة سوهاج](https://sis.gov.eg/ar/مصر/نظام-الحكم/السلطة-التنفيذية/محافظة-سوهاج/).
